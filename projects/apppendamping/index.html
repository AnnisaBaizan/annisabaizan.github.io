7-Level Budget Architecture

The defining structural feature — a strict hierarchical budget model mirroring institutional financial planning standards.

📌 This project is in the planning phase. Full specifications and API design are documented and ready for development.
Hierarchy Levels 1–4
  • L1: Program
  • L2: Activity (Kegiatan)
  • L3: Output
  • L4: Output Detail
Hierarchy Levels 5–7
  • L5: Component (Komponen)
  • L6: Sub-Component
  • L7: Account (Akun)
  • Locking mechanism per level
Access Roles
  • Admin — full system control
  • Unit — submit & view own budget
  • Budget — approve / return requests
  • JWT-based authentication

Key Features

End-to-end budget lifecycle management from planning through realization, with complete traceability.

🏗️
Hierarchical Budget Management
7-level budget structure with locking mechanism — each level can be locked to prevent further edits once approved.
📤
Budget Requests
Institutional units submit budget requests via structured header-detail forms. Full validation before submission to approval queue.
✅
Approval Workflow
Multi-step flow: Submitted → Approved or Returned. Budget role can return with notes, unit can revise and resubmit.
💰
Realization Tracking
Record actual expenditure against approved budget lines. Real-time budget vs realization comparison per account.
📁
CSV Import
Bulk upload budget data via CSV file — critical for importing large institutional budgets at the start of each fiscal year.
🔏
Audit Trail
Automatic history log for every budget change — who changed what, when, and from which value. Full immutable trail.
📊
Reporting
Budget versus realization summary reports per unit, per period, and per account level — exportable for institutional submission.
🐳
Docker Deployment
Full Docker + Docker Compose configuration for one-command deployment. Supports both containerized and manual Python/Node.js setup.

Technology Stack

Modern full-stack architecture designed for reliability, scalability, and maintainability in an institutional environment.

Frontend
  • React 18 + TypeScript
  • Vite build tool
  • Tailwind CSS + DaisyUI
  • Chart.js for reports
Backend
  • FastAPI (Python)
  • SQLAlchemy ORM
  • Alembic migrations
  • JWT authentication
Database & Infra
  • MySQL
  • Docker + Docker Compose
  • RESTful API (multiple groups)
  • Audit log tables
