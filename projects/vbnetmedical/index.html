VB.Net Medical Records App

Windows desktop application for managing dental patient medical records — covering registration, treatment history, appointment scheduling, and data export, all backed by SQL Server.

Key Features

A complete electronic dental medical record (EMR) solution for Windows — no internet required, runs fully offline.

👤
Patient Registration

Register new patients with complete demographic info, contact details, and dental history. Search and filter patients by name, ID, or date of visit.

🦷
Dental History Logging

Record per-visit treatment notes, diagnoses, procedures performed, and materials used. Full chronological history per patient.

📅
Appointment Scheduling

Schedule and manage patient appointments with date/time, treatment type, and doctor assignment. Calendar view for daily schedule overview.

📊
Reports & Data Export

Generate patient summary reports and visit statistics. Export data to PDF and Excel formats for printing and archiving.

Tech Stack

Built entirely on the Microsoft .NET ecosystem for a native Windows experience with zero external dependencies.

Language & Framework
  • Visual Basic .NET (VB.Net)
  • .NET Framework 4.x
  • Windows Forms (WinForms)
Database
  • SQL Server (LocalDB)
  • ADO.NET for data access
  • Stored Procedures
UI Components
  • DataGridView for records
  • TabControl for modules
  • Crystal Reports / PDF
Deployment
  • Windows Installer (MSI)
  • Offline — no internet
  • Single-machine setup
