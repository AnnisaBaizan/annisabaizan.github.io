Laravel Dental Clinic System

Full-featured web information system and public profile for a dental clinic — combining a patient-facing website with a complete admin dashboard for scheduling and content management.

Overview

A two-in-one system: a public-facing clinic website for patients, and a secured admin panel for the clinic owner to manage everything.

🌐
Public Clinic Profile

Patients can browse clinic information, services offered, operating hours, dentist profile, and contact details — optimized for mobile browsers.

📅
Appointment Scheduling

Online appointment booking form where patients select a date, time slot, and service type. Submissions are recorded and managed in the admin panel.

🔐
Admin Dashboard

Clinic owner logs in to manage appointments, update service listings, edit clinic content, and review patient submissions through a clean Blade-based UI.

🦷
Service Management

CRUD interface for dental service listings — name, description, price, and availability — displayed dynamically on the public-facing pages.

Architecture

Standard Laravel MVC pattern with Blade templating, Eloquent ORM, and Bootstrap for a responsive front-end.
