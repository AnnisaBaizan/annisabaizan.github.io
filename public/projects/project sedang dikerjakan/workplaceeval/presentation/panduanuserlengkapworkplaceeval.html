📖 Tentang WorkPlaceEval Pengenalan

🎯 Apa Itu WorkPlaceEval?

WorkPlaceEval adalah aplikasi web untuk mengelola penilaian mahasiswa yang sedang menjalani Praktek Kerja Lapangan (PKL) di rumah sakit, puskesmas, klinik, atau fasilitas kesehatan lainnya.

Aplikasi ini dirancang khusus untuk program studi kesehatan seperti Kebidanan, Keperawatan, dan Farmasi.

✨ Mengapa Menggunakan Ini?

  • Efisien — Tidak perlu berkas fisik
  • Terstruktur — Template penilaian standar
  • Transparan — Mahasiswa bisa lihat hasil
  • Akurat — Perhitungan otomatis
  • Aman — Data tersimpan di cloud

🌟 Fitur Utama

📋

Template Fleksibel

Buat template penilaian sesuai kebutuhan dengan berbagai tipe nilai

🔄

Alur Kerja Jelas

Draft → Submit → Approve dengan notifikasi status

🧮

Auto Calculate

Nilai total, grade, dan status lulus dihitung otomatis

🖨️

Print & Export

Cetak atau download hasil penilaian dalam format PDF

🎯 Admin: Tipe Nilai dalam Template Admin

Setiap komponen dalam template dapat menggunakan salah satu dari 4 tipe nilai berikut:

📊

Tipe: Rubrik

Pilihan dengan deskripsi detail untuk setiap level nilai.

1 = Tidak Kompeten: Tidak mampu melakukan
2 = Kurang Kompeten: Perlu bimbingan penuh
3 = Kompeten: Bisa dengan sedikit arahan
4 = Sangat Kompeten: Mandiri sempurna

🔢

Tipe: Numerik

Input angka bebas dengan batas minimum dan maksimum.

Contoh:
• Range 0-100 untuk nilai persentase
• Range 1-10 untuk skala pendek
• Bisa menggunakan desimal (75.5)

☑️

Tipe: Checklist

Pilihan Ya atau Tidak untuk item yang bersifat dikerjakan/tidak.

Contoh penggunaan:
• Cuci tangan sebelum tindakan — Ya/Tidak
• Informed consent — Ya/Tidak
• Dokumentasi lengkap — Ya/Tidak

🅰️

Tipe: Grade

Input huruf grade langsung (A, B, C, D, E).

Konversi otomatis:
A = 4 poin, B = 3 poin, C = 2 poin
D = 1 poin, E = 0 poin

💡 Kapan Menggunakan Tipe Mana?

Rubrik: Untuk kompetensi dengan kriteria jelas. Numerik: Untuk nilai bebas. Checklist: Untuk item ya/tidak. Grade: Untuk penilaian langsung dengan huruf.

✅ Admin: Approval Penilaian Admin

🔄 Alur Approval

Pembimbing mengisi
→
SUBMITTED

→
APPROVED
Disetujui ✓

✅ Jika APPROVE

  • Status berubah menjadi "Approved"
  • Nilai menjadi final dan tidak bisa diubah
  • Mahasiswa bisa melihat hasil penilaiannya
  • Penilaian bisa dicetak/download
  • Tercatat siapa yang approve dan kapan

❌ Jika REJECT

  • Status berubah menjadi "Rejected"
  • Admin wajib mengisi alasan penolakan
  • Pembimbing menerima notifikasi
  • Pembimbing perlu memperbaiki dan submit ulang
  • Mahasiswa belum bisa melihat nilai
💡 Tips Review Penilaian

Periksa: (1) Semua komponen wajib terisi, (2) Nilai sesuai dengan range, (3) Feedback sudah ditulis, (4) Tanggal penilaian wajar.

🧮 Sistem Perhitungan Nilai Info

WorkPlaceEval mendukung 3 metode perhitungan nilai total:

➗

Rata-rata (Average)

Semua nilai komponen dijumlah lalu dibagi jumlah komponen.

Contoh:
(80 + 75 + 90) ÷ 3 = 81.67

⚖️

Berbobot (Weighted)

Setiap kategori memiliki bobot (%). Nilai dikalikan bobot.

Contoh:
(80×30%) + (90×70%) =
24 + 63 = 87

➕

Penjumlahan (Sum)

Semua nilai komponen dijumlahkan secara langsung.

Contoh:
15 + 18 + 12 = 45
(dari max 60)

🎓 Konversi ke Grade

A
≥ 85%
Sangat Baik
B
75 - 84%
Baik
C
65 - 74%
Cukup
D
55 - 64%
Kurang
E
< 55%
Sangat Kurang
✅ Status Kelulusan

Mahasiswa dinyatakan LULUS jika nilai total ≥ Nilai Lulus yang ditetapkan di template (umumnya 70). Jika di bawah nilai lulus, status TIDAK LULUS.

❓ FAQ - Pertanyaan Umum Bantuan

Saya lupa password, bagaimana cara resetnya?
Klik link "Lupa Password?" di halaman login, masukkan email Anda, lalu cek inbox email (termasuk folder Spam) untuk link reset password.
Kenapa nilai saya belum muncul padahal sudah dinilai?
Mahasiswa hanya bisa melihat penilaian yang statusnya "Approved". Jika pembimbing baru submit, nilai masih menunggu persetujuan Admin. Hubungi Admin untuk informasi lebih lanjut.
Apakah nilai bisa diubah setelah disubmit?
Tidak. Setelah pembimbing klik Submit, nilai tidak bisa diubah. Jika Admin menolak (reject), pembimbing bisa memperbaiki dan submit ulang.
Saya tidak muncul di daftar mahasiswa pembimbing, kenapa?
Kemungkinan Admin belum membuat penempatan PKL untuk Anda. Hubungi Admin untuk memastikan data penempatan sudah diinput dengan benar.
Apakah bisa diakses dari HP/tablet?
Ya, aplikasi bersifat responsive dan bisa diakses dari browser di HP atau tablet. Namun untuk pengalaman terbaik, gunakan laptop/komputer.
Bagaimana cara mencetak hasil penilaian?
Buka detail penilaian (status Approved), klik ikon printer atau download, lalu pilih print atau save as PDF.

❓ FAQ - Untuk Admin Bantuan

Bagaimana cara mengubah password user yang lupa?
Buka menu Pengguna, cari user yang bersangkutan, klik Edit, lalu isi field password baru. Informasikan password baru ke user tersebut dan sarankan untuk segera menggantinya.
Bagaimana jika bobot kategori tidak mencapai 100%?
Sistem akan menampilkan peringatan. Pastikan total bobot semua kategori dalam satu template tepat 100%. Jika tidak, perhitungan weighted tidak akurat.
Bisakah template yang sudah dipakai dihapus?
Template yang sudah memiliki penilaian tidak bisa dihapus untuk menjaga integritas data. Anda hanya bisa menonaktifkannya agar tidak muncul di pilihan pembimbing.
Bagaimana cara bulk import data pengguna?
Fitur bulk import akan tersedia di versi mendatang. Saat ini, penambahan user dilakukan satu per satu melalui form. Untuk import banyak user sekaligus, hubungi tim teknis.
Apa yang terjadi jika saya nonaktifkan program studi?
Program yang dinonaktifkan tidak akan muncul di dropdown pilihan, namun data historis tetap tersimpan. Pengguna yang terkait dengan program tersebut masih bisa login dan melihat data lama.
Bagaimana cara melihat log aktivitas sistem?
Fitur audit log akan tersedia di versi mendatang. Saat ini, Anda bisa melihat aktivitas terbaru dari dashboard dan daftar penilaian.

❓ FAQ - Untuk Pembimbing Bantuan

Mahasiswa saya tidak muncul di daftar penilaian, kenapa?
Kemungkinan besar Admin belum membuat penempatan PKL untuk mahasiswa tersebut, atau Anda belum ditugaskan sebagai pembimbingnya. Hubungi Admin untuk verifikasi data penempatan.
Bisakah saya menilai satu mahasiswa lebih dari sekali?
Ya, Anda bisa membuat beberapa penilaian untuk mahasiswa yang sama menggunakan template yang sama atau berbeda. Setiap penilaian adalah record terpisah.
Bagaimana jika saya salah mengisi nilai tapi sudah submit?
Hubungi Admin dan jelaskan kesalahannya. Admin bisa menolak (reject) penilaian tersebut agar Anda bisa memperbaikinya dan submit ulang.
Apakah draft penilaian akan hilang jika saya logout?
Tidak, draft tersimpan di database. Anda bisa logout dan login kembali kapan saja, draft akan tetap ada dan bisa dilanjutkan.
Berapa lama proses approval oleh Admin?
Tergantung kebijakan institusi, biasanya 1-3 hari kerja. Jika lebih lama, hubungi Admin untuk konfirmasi.
Bisakah saya melihat penilaian yang dibuat pembimbing lain?
Tidak, Anda hanya bisa melihat dan mengelola penilaian yang Anda buat sendiri. Ini untuk menjaga privasi dan akuntabilitas penilaian.

❓ FAQ - Untuk Mahasiswa Bantuan

Kapan saya bisa melihat nilai saya?
Anda bisa melihat nilai setelah pembimbing submit penilaian DAN Admin menyetujuinya (Approved). Jika status masih Draft atau Submitted, nilai belum bisa dilihat.
Kenapa nilai saya tidak ada padahal sudah praktik?
Kemungkinan: (1) Pembimbing belum membuat penilaian, (2) Penilaian masih draft/belum disubmit, (3) Admin belum approve. Hubungi pembimbing untuk konfirmasi.
Apakah saya bisa komplain jika merasa nilai tidak adil?
Anda bisa menghubungi pembimbing untuk diskusi. Jika diperlukan, bawa ke koordinator prodi atau bagian akademik sesuai prosedur kampus.
Bagaimana jika data penempatan saya salah?
Segera hubungi Admin dengan menyebutkan data yang salah dan koreksinya. Admin akan memperbaiki data penempatan Anda.
Apakah hasil penilaian bisa digunakan untuk melamar kerja?
Hasil penilaian dari aplikasi ini adalah untuk dokumentasi internal. Untuk keperluan resmi seperti melamar kerja, gunakan transkrip atau surat keterangan dari bagian akademik kampus.
Bisakah saya melihat nilai teman saya?
Tidak, setiap mahasiswa hanya bisa melihat nilai dirinya sendiri. Ini untuk menjaga privasi data akademik.
