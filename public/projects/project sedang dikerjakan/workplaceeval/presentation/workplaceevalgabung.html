Tentang WorkPlaceEval

🌐

Berbasis Web

Akses langsung via browser tanpa instalasi. Compatible dengan semua device: PC, laptop, tablet.

☁️

Cloud Based

Data tersimpan aman di server dengan backup otomatis. Akses dari mana saja, kapan saja.

👥

Multi-User RBAC

5 level akses berbeda: Admin, Dosen, Pembimbing Institusi, Pembimbing Klinik, dan Mahasiswa.

🔄

Real-Time Sync

Update data langsung tersinkron. Monitoring mahasiswa bisa dilakukan kapan saja secara real-time.

🎯 Tujuan Utama:

Memudahkan pembimbing dalam menilai mahasiswa, admin dalam mengelola sistem, dan mahasiswa dalam melihat progress penilaian PKL mereka secara terintegrasi.

Struktur Template Penilaian

📋 Hierarki Template:

Template → Kategori (dengan bobot) → Komponen (dengan tipe nilai) → Rubrik/Kriteria

📋 Assessment Template
├── Kategori 1 Bobot: 30%
│   ├── Komponen A RUBRIC
│   │   ├── 1: Tidak Kompeten
│   │   ├── 2: Kurang Kompeten
│   │   ├── 3: Kompeten
│   │   └── 4: Sangat Kompeten
│   └── Komponen B NUMERIC 0-100
├── Kategori 2 Bobot: 40%
│   └── Komponen C CHECKLIST
└── Kategori 3 Bobot: 30%

4 Tipe Nilai

Rubric: Pilihan dengan deskripsi
Numeric: Angka dengan range
Checklist: Ya/Tidak
Grade: Huruf A-E

3 Metode Perhitungan

Average: Rata-rata semua nilai
Weighted: Berbobot per kategori
Sum: Jumlah total

Penentuan Grade & Kelulusan

A
≥ 85%
B
75 - 84%
C
65 - 74%

📊 Rumus Perhitungan

Average:
Total = Σ Scores / n

Weighted:
Total = Σ (Score × Weight) / Σ Weight

Percentage:
% = (Total / Max) × 100

✅ Status Kelulusan

  • LULUS Score ≥ Passing Score
  • TIDAK LULUS Score < Passing Score

Passing score ditentukan per template. Default: 65% dari max score.

Fitur Pembimbing

🎯 Quick Access:

Dari dashboard, langsung klik "Nilai" di daftar mahasiswa untuk mulai penilaian baru.

Kemampuan Pembimbing

  • Lihat Mahasiswa Bimbingan - Daftar semua mahasiswa dengan placement aktif yang Anda bimbing
  • Buat Penilaian Baru - Pilih mahasiswa → template → isi nilai per komponen
  • Simpan Draft - Simpan progress, lanjutkan kapan saja
  • Submit Penilaian - Kirim ke admin untuk approval (nilai otomatis terhitung)
  • Lihat Riwayat - Semua penilaian yang pernah Anda buat dengan filter status
  • Cetak Penilaian - Print-friendly view untuk dokumentasi

⚠️ Batasan

  • Hanya bisa menilai mahasiswa bimbingan sendiri
  • Tidak bisa edit setelah submit
  • Tidak bisa approve penilaian sendiri

💡 Tips

  • Isi catatan per komponen untuk feedback detail
  • Klik "Lihat Rubrik" untuk referensi kriteria
  • Simpan draft secara berkala

Keamanan & Otorisasi

🔐

Password Hashing

Semua password di-hash dengan bcrypt. Tidak ada yang bisa melihat password asli, termasuk admin.

🛡️

CSRF Protection

Semua form dilindungi CSRF token. Mencegah cross-site request forgery attacks.

👮

Policy-Based Auth

Setiap aksi dicek dengan Laravel Policy. User hanya bisa akses resource yang diizinkan.

🚦

Middleware Guards

Route protection dengan custom middleware (CheckAdmin, CheckSupervisor, CheckStudent).

🔒 Assessment Policy:

• View: Admin semua, Assessor milik sendiri, Student milik sendiri (approved only)
• Update: Assessor milik sendiri (draft only)
• Delete: Admin semua, Assessor milik sendiri (draft only)
• Approve: Admin only (status submitted)
