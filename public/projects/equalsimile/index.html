EqualSmile

A voice-guided web navigation tool making dental health information and services fully accessible to blind and low-vision users — through audio guidance, screen reader optimization, and keyboard-only navigation.

The Mission

Dental health information should be accessible to everyone — including the estimated 285 million visually impaired people worldwide who face barriers navigating standard web interfaces.

🚧 This project is currently under active development. Demo and documentation will be available soon.
The Problem
  • Dental health sites lack accessibility
  • Screen readers often fail on complex UIs
  • No audio guidance for navigation
  • Forms inaccessible without mouse
  • Low-contrast designs for low-vision
EqualSmile's Approach
  • Full Web Speech API voice guidance
  • Semantic HTML + ARIA labels
  • Keyboard-only navigation support
  • High contrast configurable display
  • Dental health content focus
Target Users
  • Blind users relying on screen readers
  • Low-vision users needing contrast
  • Motor-impaired keyboard-only users
  • Dental patients seeking information
  • Caregivers assisting patients

Key Features

Purpose-built accessibility features ensuring every interaction is navigable without sight.

🔊
Voice Navigation
Audio guidance walks users through all interface elements, announcing options, reading content, and confirming actions via Web Speech API.
♿
Screen Reader Optimized
Full ARIA label coverage, semantic HTML throughout, and focus management ensuring compatibility with NVDA, JAWS, and VoiceOver.
🌗
High Contrast Mode
Configurable visual display with multiple high-contrast themes for users with varying degrees of low vision.
💬
Text-to-Speech
All content is automatically read aloud. Users can control speech rate, volume, and voice selection from an accessible preferences panel.
⌨️
Keyboard-Only Navigation
Every feature accessible via keyboard shortcuts. Logical tab order and skip-navigation links minimize effort to reach main content.
🦷
Dental Health Focus
Accessible dental health information, appointment guidance, and oral care instructions — content designed for comprehension by all users.

Technology Stack

Built with web standards and progressive enhancement — no frameworks required for core accessibility.

Laravel 9 PHP 8.0 Vue 3 MySQL Bootstrap 5 Laravel Sanctum WCAG 2.1
